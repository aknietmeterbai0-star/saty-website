# Saty — Marketplace Landing

Төрт логикалық өзара байланысты беттен тұратын адаптивті лендинг (қосымша Contacts және Policy беттерімен).
Фреймворксіз — тек HTML5, CSS3 және аз мөлшердегі vanilla JavaScript (баға калькуляторы үшін).


```
.
├── index.html               # Home — промо, жоба туралы, санаттар, артықшылықтар, CTA, пікірлер
├── for-seller.html          # For Seller — жариялау нұсқаулығы (storytelling), артықшылықтар, FAQ
├── seller-advantages.html   # For Seller — Advantages: баға тізімі + range-калькулятор, артықшылықтар, FAQ
├── for-buyer.html           # For Buyer — сатып алу нұсқаулығы (storytelling), артықшылықтар, FAQ
├── contacts.html            # Contacts — кері байланыс формасы, байланыс деректері, әлеуметтік желілер, карта
├── policy.html              # Policy — құпиялылық саясаты
├── css/
│   └── style.css            # Барлық стильдер (CSS-тенгіштер, микро-анимациялар, адаптив)
├── media-files/
│   └── map.png              # Карта (орнын нақты картамен алмастырыңыз)
└── README.md
```

## Іске қосу (Жариялау / Опубликовать)

Бұл жоба статикалық — құрастыру (build) қажет емес.

1. GitHub-қа жүктеу:
   - Репозиторий жасап, файлдарды жіберіңіз;
   - **Settings → Pages → Source** ішінде `main` тармағын таңдаңыз → **Save**.
2. Платформа нәтижесінде берген сілтеме — сіздің тіркеуіңіз.
3. Немесе файлдарды кез келген статикалық хостингке (Netlify, Vercel, хостингтің public_html қалтасы) салыңыз.

Басқа жобаға көшірсеңіз, файлы `css/style.css` және `js` (қарапайым ішкі `<script>`) жолдары салыстырмалы болғандықтан бары қайда салсаңыз да жұмыс істейді.

## Қарау (Посмотреть)

Локалды қарау үшін `index.html` файлын браузерде ашыңыз (сыртқы сервер қажет емес).

## Publish және View батырмаларының сілтемелерін өзгерту

Батырмалар **барлық беттерде** `<header>` ішінде орналасқан:

```html
<div class="header-actions">
  <a href="for-seller.html" class="btn" data-type="primary">Publish</a>
  <a href="for-buyer.html"  class="btn" data-type="ghost">View</a>
</div>
```

- **`href`** атрибутын ауыстырып, батырманы кез келген бетке немесе сыртқы сілтемеге бағыттаңыз:
  `<a href="https://app.saty.kz/new" ...>Publish</a>`.
- Егер беттер шапшаң атын өзгертсеңіз, 6 HTML файлдың бәрінде бірдей ауыстырыңыз
  (жалпыға ортақ фрагмент жоқ, фреймворксіз талапқа сәйкес).

### Стильді ауыстыру — `data-type` атрибуты

Батырманың сыртқы түрі `data-type` атрибутымен басқарылады (`css/style.css` ішінде):

| Мәні               | Сипаттамасы                              |
|--------------------|------------------------------------------|
| `data-type="primary"` | Толық жасыл батырма (негізгі әрекет)     |
| `data-type="ghost"`   | Контурлы/мөлдір батырма (қосымша әрекет) |

```html
<!-- Стиль 2 (контурлы) жасалған Publish -->
<a href="..." class="btn" data-type="ghost">Publish</a>
```

## Ескертулер

- Мобильді мәзір чекбокс-хак арқылы, екінші деңгейлі мәзір — тек CSS hover арқылы жасалған (JavaScript қолданылмаған).
- FAQ `<details>/<summary>` элементтерімен, JS-сіз ашылған.
- `media-files/map.png` — орнын баспа: нақты картамен (`<iframe>` Google Maps немесе скриншот) алмастырыңыз.
- Тапсырмада көрсетілген `media-files/texts/*.txt` файлдары жобаға қосылмағандықтан, мәтіндер тапсырма құрылымына сәйкес авторлық түрде жазылған.
